## 🗄️ 二、全局數據模型設計 (Zustand Schema)

### 1. 員工數據模型 (Employee)

```typescript
interface Employee {
  id: string;
  name: string;
  avatar: string;
  email: string;
  department: 'Engineering' | 'HR' | 'Marketing' | 'Sales' | 'Finance';
  role: string;
  salary: number;
  status: 'Active' | 'On Leave' | 'Terminated';
  joinDate: string;
}
```

**Flutter 對應**：

```dart
class Employee {
  final String id;
  final String name;
  final String avatar;
  final String email;
  final Department department;  // enum Department { engineering, hr, marketing, sales, finance }
  final String role;
  final int salary;
  final EmployeeStatus status;  // enum EmployeeStatus { active, onLeave, terminated }
  final String joinDate;

  Employee({...});
}
```

| TS 字段 | Flutter 對應 | 說明 |
|---|---|---|
| `string` 聯合類型 | `enum` | TS 用字面量聯合類型替代枚舉，更簡潔 |
| `id: string` | `id: String` | TS 用 `Date.now().toString(36)` 生成 |
| `salary: number` | `salary: int` | TS 的 number 包含整數和浮點數 |

> **Flutter 對應**：`GridView.count` + `PieChart`（fl_chart）+ `BarChart`

本頁面所有數據必須由 Zustand 中的 `employees` 和 `leaveRequests` 數組通過純 JS 函數實時計算得出，不允許硬編碼。

#### 2.1 指標卡片組 (Grid Metrics)

佈局：`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4`

| 序號 | 指標名稱 | 計算邏輯 | 圖標 | 卡片顏色 |

| 4 | 待處理審批數 | `leaveRequests.filter(r => r.status === 'Pending').length` | `Clock` | 紫色系 `bg-purple-50 dark:bg-purple-950` |

#### 2.2 圖表分析組 (Analytics Section)

佈局：`grid grid-cols-1 lg:grid-cols-2 gap-6 mt-6`

**部門人數分佈圖 (PieChart)**：

- 使用 JS `.reduce()` 統計各部門人數
- 輸出格式：`[{ name: 'Engineering', value: 5, fill: '#3b82f6' }]`
- 餵給 Recharts 的 `<PieChart><Pie data={data} dataKey="value" nameKey="name" cx="50%" cy="50%" outerRadius={80}><Tooltip /></Pie></PieChart>`
- 圖表需支持 Tooltip 懸浮提示
- 顏色映射：Engineering=#3b82f6, HR=#10b981, Marketing=#f59e0b, Sales=#ef4444, Finance=#8b5cf6

> **Flutter 對應**：`PieChart(PieChartData(sections: [...]))` from fl_chart

**薪資結構對比圖 (BarChart)**：

- 橫軸為各部門名稱，縱軸為該部門的平均薪資

- 使用 `<BarChart><Bar dataKey="avgSalary" fill="#3b82f6" radius={[4,4,0,0]} /><XAxis dataKey="department" /><YAxis /><Tooltip /></BarChart>`

> **Flutter 對應**：`BarChart(BarChartData(barGroups: [...]))` from fl_chart

#### 4.2 拖拽核心邏輯 (Drag & Drop Logic)

- 將整個區域包裹在 `@hello-pangea/dnd` 的 `DragDropContext` 中
- 每一列為一個 `Droppable` 區域，內部根據請假單狀態 `.filter()` 出對應數據，用 `.map()` 渲染卡片
- 每個請假單卡片為一個 `Draggable` 元素
- 狀態變更回調 (`onDragEnd`)：

```typescript
const handleDragEnd = (result: DropResult) => {
  if (!result.destination) return;
  const { draggableId, destination } = result;
  const newStatus = destination.droppableId as 'Pending' | 'Approved' | 'Rejected';
  updateLeaveStatus(draggableId, newStatus);
};
```

> **Flutter 對應**：
> ```dart

>   },

### 5. 全局系統特性 (Cross-Cutting Requirements)

#### 5.1 數據持久化 (LocalStorage Persist)

- 利用 Zustand 的 `persist` 中間件配置 `name: 'hrm-storage'`
- 要求手動刷新瀏覽器、或者關閉標籤頁重新打開後，之前新增的員工、修改的審批狀態必須完好保留
- `partialize` 配置：只持久化 `employees` 和 `leaveRequests`，不持久化 UI 狀態

> **Flutter 對應**：`SharedPreferences` + JSON 序列化，或 `Hive` 數據庫

#### 5.2 高級暗黑模式 (Dark Mode)

- 集成 `next-themes` 庫
- 在根節點配置 `dark:` 變體
- 系統文字顏色由 `text-slate-900` 轉為 `text-slate-50`
- 背景由 `bg-white` 轉為 `bg-zinc-950`
- Shadcn UI 組件需完美適應此切換
- 支持三種模式：亮色 / 暗色 / 跟隨系統

> **Flutter 對應**：`ThemeData(brightness: isDark ? Brightness.dark : Brightness.light)` + `MediaQuery.platformBrightness`

#### 5.3 空狀態處理

- 員工列表為空時顯示空狀態插圖 + 「添加第一位員工」按鈕
- 搜索無結果時顯示「未找到匹配的員工」
- 請假看板某列為空時顯示「暫無待處理申請」

> **Flutter 對應**：`if (items.isEmpty) return EmptyWidget();`

## 🔑 六、核心知識點 Flutter ↔ React/Tailwind 對照速查

### 佈局類

| Flutter | React + Tailwind | 說明 |
|---|---|---|
| `Row(children: [...])` | `<div className="flex">` | 水平排列 |
| `Column(children: [...])` | `<div className="flex flex-col">` | 垂直排列 |
| `Expanded(child: ...)` | `<div className="flex-1">` | 撐開剩餘空間 |
| `SizedBox(width: 16)` | `<div className="w-4">` | 固定間距 |
| `ListView.builder` | `array.map()` | 列表渲染 |
| `GridView.count(crossAxisCount: 3)` | `<div className="grid grid-cols-3">` | 網格佈局 |
| `Stack(children: [...])` | `<div className="relative">` + `absolute` | 層疊佈局 |
| `Positioned(top:0, right:0)` | `<div className="absolute top-0 right-0">` | 絕對定位 |
| `SingleChildScrollView` | `<div className="overflow-y-auto">` | 滾動容器 |
| `MediaQuery` 判斷寬度 | `md:` `lg:` 前綴 | 響應式斷點 |

### 狀態管理類

| Flutter | React + Zustand | 說明 |
|---|---|---|
| `StatefulWidget + setState` | `useState` | 局部狀態 |
| `ChangeNotifier + Provider` | `Zustand Store` | 全局狀態 |
| `notifyListeners()` | `set()` (Zustand 自動觸發) | 通知更新 |
| `SharedPreferences` | `Zustand persist middleware` | 數據持久化 |
| `Provider.of<T>(context)` | `useStore(selector)` | 讀取狀態 |
| `Consumer<T>(builder: ...)` | `useStore` + 組件渲染 | 監聽狀態變化 |

### 組件類

| Flutter | React + Shadcn | 說明 |
|---|---|---|
| `ElevatedButton` | `<Button>` | 主要按鈕 |
| `TextButton` | `<Button variant="ghost">` | 文字按鈕 |
| `TextField` | `<Input>` | 輸入框 |
| `DropdownButton` | `<Select>` | 下拉選擇 |
| `AlertDialog` | `<AlertDialog>` | 確認對話框 |
| `DataTable` | `<Table>` | 數據表格 |
| `Chip` | `<Badge>` | 標籤/徽章 |
| `CircularProgressIndicator` | `<Loader2 className="animate-spin" />` | 加載指示器 |
| `BottomNavigationBar` | Tab 切換 + Sidebar | 導航切換 |

### 樣式類

| Flutter | Tailwind | 說明 |
|---|---|---|
| `EdgeInsets.all(16)` | `p-4` | 全方向內邊距 |
| `BorderRadius.circular(8)` | `rounded-lg` | 圓角 |
| `BoxShadow(color, blurRadius)` | `shadow-sm` | 陰影 |
| `TextStyle(fontSize: 14, fontWeight: FontWeight.bold)` | `text-sm font-bold` | 文字樣式 |
| `Colors.blue` | `bg-blue-500` | 顏色 |
| `ThemeData(brightness: dark)` | `dark:` 前綴 | 暗黑模式 |
