> 本模塊在 4.1 基礎模塊（Dashboard + 員工名冊 + 請假審批）之上，新增 4 個實戰模塊。

### 1. 考勤記錄 (AttendanceRecord)

```typescript
interface AttendanceRecord {
  id: string
  employeeId: string
  employeeName: string
  date: string            // 'YYYY-MM-DD'
  clockIn: string         // 'HH:mm'
  clockOut: string | null // null = 未打卡
  status: 'Normal' | 'Late' | 'Early Leave' | 'Absent' | 'On Leave'
  workHours: number       // 計算得出，小時數
}
```

**Flutter 對應**：

```dart
class AttendanceRecord {
  final String id;
  final String employeeId;
  final String employeeName;
  final String date;           // DateFormat('yyyy-MM-dd')
  final String clockIn;        // DateFormat('HH:mm')
  final String? clockOut;      // nullable
  final AttendanceStatus status; // enum AttendanceStatus { normal, late, earlyLeave, absent, onLeave }
  final double workHours;
}
```

| TS 字段 | Flutter 對應 | 說明 |
|---|---|---|
| `clockOut: string \| null` | `String? clockOut` | TS 用聯合類型 + null，Flutter 用 nullable |
| `status` 聯合類型 | `enum AttendanceStatus` | TS 字面量聯合 vs Flutter enum |
| `workHours: number` | `double workHours` | TS number 包含 int/float |

**模擬打卡邏輯**：

```typescript
const generateDailyAttendance = () => {
  const today = format(new Date(), 'yyyy-MM-dd')
  const activeEmployees = employees.filter(e => e.status === 'Active')
  const records = activeEmployees.map(emp => {
    const rand = Math.random()
    let status: AttendanceRecord['status']
    let clockIn: string
    let clockOut: string | null
    let workHours: number

    if (rand < 0.75) {        // 75% 正常
      status = 'Normal'
      clockIn = `0${8 + Math.floor(Math.random() * 1)}:${String(Math.floor(Math.random() * 30)).padStart(2, '0')}`
      clockOut = `1${7 + Math.floor(Math.random() * 2)}:${String(Math.floor(Math.random() * 60)).padStart(2, '0')}`
      workHours = 8.0 + Math.random() * 1.5
    } else if (rand < 0.88) { // 13% 遲到
      status = 'Late'
      clockIn = `${9 + Math.floor(Math.random() * 2)}:${String(10 + Math.floor(Math.random() * 50)).padStart(2, '0')}`
      clockOut = `1${8 + Math.floor(Math.random() * 1)}:${String(Math.floor(Math.random() * 60)).padStart(2, '0')}`
      workHours = 7.0 + Math.random()
    } else if (rand < 0.95) { // 7% 早退
      status = 'Early Leave'
      clockIn = `0${8 + Math.floor(Math.random() * 1)}:${String(Math.floor(Math.random() * 30)).padStart(2, '0')}`
      clockOut = `1${4 + Math.floor(Math.random() * 2)}:${String(Math.floor(Math.random() * 60)).padStart(2, '0')}`
      workHours = 6.0 + Math.random()
    } else {                  // 5% 缺勤
      status = 'Absent'
      clockIn = '—'
      clockOut = null
      workHours = 0
    }

    return {
      id: `ATT${Date.now().toString(36)}${emp.id}`,
      employeeId: emp.id,
      employeeName: emp.name,
      date: today,
      clockIn,
      clockOut,
      status,
      workHours: Math.round(workHours * 10) / 10,
    }
  })
  addAttendanceRecords(records)
}
```

**薪資生成邏輯**：

```typescript
const generateMonthlyPayroll = (month: string) => {
  const activeEmployees = employees.filter(e => e.status === 'Active')
  const records = activeEmployees.map(emp => {
    const baseSalary = emp.salary
    const bonus = Math.random() > 0.6 ? Math.round(baseSalary * (0.05 + Math.random() * 0.15)) : 0
    const deduction = Math.random() > 0.8 ? Math.round(baseSalary * 0.02) : 0
    const insurance = Math.round(baseSalary * 0.105)  // 10.5% 五險一金
    const taxableIncome = baseSalary + bonus - deduction - insurance - 5000  // 起徵點 5000
    const tax = taxableIncome > 0 ? Math.round(taxableIncome * (taxableIncome > 36000 ? 0.1 : 0.03)) : 0
    const netSalary = baseSalary + bonus - deduction - insurance - tax

    return {
      id: `PAY${Date.now().toString(36)}${emp.id}`,
      employeeId: emp.id,
      employeeName: emp.name,
      department: emp.department,
      month,
      baseSalary,
      bonus,
      deduction,
      insurance,
      tax,
      netSalary,
      status: 'Draft' as const,
    }
  })
  addPayrollRecords(records)
}
```

## 🔧 七、全局系統特性（延續 4.1）

### 數據持久化

每個新 Store 均配置 `persist` 中間件：

```typescript
persist(
  (set) => ({ ... }),
  {
    name: 'hrm-attendance-storage',  // 各 Store 獨立 storage key
    partialize: (state) => ({
      records: state.records,
    }),
  }
)
```

> **Flutter 對應**：`Hive` 多 Box 或 `SharedPreferences` 多 key

### 暗黑模式

所有新組件必須同時支持 `dark:` 變體，遵循 4.1 的色彩系統。

### 空狀態處理

- 考勤表為空：「點擊「模擬打卡」生成今日考勤」
- 薪資表為空：「點擊「生成薪資單」創建本月薪資」
- 招聘看板某列為空：「暫無開放職位」
- 培訓列表為空：「暫無培訓課程」

> **Flutter 對應**：`if (items.isEmpty) return EmptyWidget();`
