# 🚀 HRM 高級模塊 — 詳細需求文檔

> 本模塊在 4.1（基礎）+ 4.2（進階）之上，新增 4 個高級實戰模塊。
> 適合已完成 4.1 + 4.2 的初中級開發者，每個模塊引入新的技術挑戰。
> 所有功能均標注 Flutter 對應知識點，延續「從 Flutter 到 React」的學習路徑。

---

## 🛠️ 一、技術選型（延續 + 新增）

| 項目 | 技術 | 說明 |
|---|---|---|
| 構建 | Vite + React + TypeScript | 同 4.1 |
| 樣式 | Tailwind CSS | 同 4.1 |
| UI 組件 | Shadcn UI | 同 4.1 |
| 狀態管理 | Zustand | 新增 4 個 Slice |
| 數據可視化 | Recharts | 績效雷達圖、報表多維圖表 |
| 日期處理 | date-fns | 績效週期、報表日期範圍 |
| 圖標 | Lucide React | 同 4.1 |

```bash
npm install date-fns
# Recharts 已在 4.2 安裝
```

## 🗄️ 二、新增數據模型

### 1. 績效評估 (PerformanceReview)

```typescript
interface PerformanceReview {
  id: string
  employeeId: string
  employeeName: string
  department: Department
  period: string            // 'YYYY-H1' 或 'YYYY-H2'
  reviewerId: string
  reviewerName: string
  scores: {
    quality: number         // 1-5 工作質量
    efficiency: number      // 1-5 工作效率
    teamwork: number        // 1-5 團隊協作
    initiative: number      // 1-5 主動性
    communication: number   // 1-5 溝通能力
  }
  overallScore: number      // 加權平均 1-5
  grade: 'S' | 'A' | 'B' | 'C' | 'D'
  comments: string
  status: 'Self Review' | 'Manager Review' | 'HR Review' | 'Completed'
  createdAt: string
  updatedAt: string
}
```

**Flutter 對應**：

```dart
class PerformanceReview {
  final String id;
  final String employeeId;
  final String employeeName;
  final Department department;
  final String period;
  final String reviewerId;
  final String reviewerName;
  final Scores scores;          // class Scores { final double quality, efficiency, teamwork, initiative, communication; }
  final double overallScore;
  final PerformanceGrade grade; // enum PerformanceGrade { S, A, B, C, D }
  final String comments;
  final ReviewStatus status;    // enum ReviewStatus { selfReview, managerReview, hrReview, completed }
  final String createdAt;
  final String updatedAt;
}
```

### 模塊 A：績效管理 (Performance Module)

> **技術挑戰**：多維度評分 + 雷達圖 + 審批流程 + 等級計算
> **Flutter 對應**：`RadarChart`（fl_chart）+ `Stepper` + `Slider`

#### A1. 績效總覽頁 (PerformanceOverview)

**頂部統計卡片**：`grid grid-cols-2 md:grid-cols-4 gap-4`

| 指標 | 計算邏輯 | 圖標 | 顏色 |
|---|---|---|---|
| 本期評估人數 | `Completed 數量` | `Users` | 藍色 |
| 平均績效分 | `overallScore 平均值` | `TrendingUp` | 綠色 |
| S/A 級佔比 | `(S+A) / total * 100` | `Award` | 紫色 |
| 待審核數 | `非 Completed 數量` | `Clock` | 橙色 |

**績效分佈柱狀圖**（Recharts BarChart）：

- 橫軸：等級 S / A / B / C / D
- 縱軸：人數
- 每個柱子顏色不同：S=紫色, A=藍色, B=綠色, C=橙色, D=紅色

**部門績效對比圖**（Recharts BarChart 橫向）：

- 橫軸：平均分
- 縱軸：部門名稱
- 按分數排序

> **Flutter 對應**：`fl_chart` 的 `BarChart` + `BarChartGroupData`

#### A2. 績效評估列表 (PerformanceList)

**篩選工具欄**：

| 組件 | 功能 |
|---|---|
| 週期選擇 | Select: '2026-H1' / '2026-H2' |
| 部門篩選 | Select |
| 等級篩選 | Select: S/A/B/C/D/全部 |
| 狀態篩選 | Select: 審批流程狀態 |

**表格列**：

| 列名 | 字段 | 樣式 |
|---|---|---|
| 員工 | avatar + name | 同 4.1 |
| 部門 | department | Badge |
| 週期 | period | `font-mono` |

| 等級 | grade | 大號 Badge（S=紫, A=藍, B=綠, C=橙, D=紅） |
| 狀態 | status | 審批流程 Badge |
| 評審人 | reviewerName | 文本 |

**總評區域**：

#### A4. 新增績效評估彈窗 (PerformanceForm)

**表單字段**：

| 行 | 字段 | 佈局 | 控件 |
|---|---|---|---|
| 1 | 員工選擇 | 全寬 | Select（從員工列表選擇） |
| 2 | 評估週期 + 評審人 | `grid-cols-2` | Select + Select |

**Slider 評分控件**：

```tsx
<div className="flex items-center gap-4">
  <label className="w-24 text-sm">{label}</label>
  <input type="range" min="1" max="5" step="0.5" value={value}
    onChange={(e) => onChange(Number(e.target.value))}
    className="flex-1 accent-blue-500" />
  <span className="w-8 text-center font-mono">{value}</span>
</div>
```

> **Flutter 對應**：`Slider(min: 1, max: 5, divisions: 8, label: value.toString())`

**等級自動計算**：

```typescript
function calculateGrade(score: number): Grade {
  if (score >= 4.5) return 'S'
  if (score >= 4.0) return 'A'
  if (score >= 3.0) return 'B'
  if (score >= 2.0) return 'C'
  return 'D'
}
```

## 🔄 四、跨模塊交互

### 4.1 績效 ↔ 薪資

- 績效等級影響獎金係數：S=1.5, A=1.2, B=1.0, C=0.8, D=0.5
- 薪資模塊計算獎金時讀取績效等級

### 4.2 通知 ↔ 所有模塊

- 請假申請 → 通知主管
- 考勤異常 → 通知員工和 HR
- 薪資確認 → 通知員工
- 績效待評 → 通知評審人

### 4.3 報表 ↔ 所有模塊

- 人數報表讀取員工數據
- 考勤報表讀取考勤數據
- 薪資報表讀取薪資數據
- 績效報表讀取績效數據

### 4.4 設置 ↔ 所有模塊

- 考勤設置影響遲到/早退判定
- 假期設置影響請假天數上限
- 薪資設置影響稅率計算

## 🎯 六、技術要點與 Flutter 對照

| 4.3 技術點 | React 實現 | Flutter 對應 |
|---|---|---|
| 雷達圖 | Recharts `RadarChart` | `fl_chart` `RadarChart` |
| Slider 評分 | `<input type="range">` | `Slider` Widget |
| 審批流程 | 自定義 Stepper 組件 | `Stepper` Widget |
| 日期範圍 | 雙 Input[type=date] | `showDateRangePicker` |
| 可編輯表格 | Table + Input 切換 | `DataTable` + `TextFormField` |
| 拖拽排序 | `@hello-pangea/dnd` | `ReorderableListView` |
| Switch 開關 | `<input type="checkbox">` + 樣式 | `Switch` Widget |
| Radio 單選 | `<input type="radio">` + 樣式 | `Radio` Widget |
| 未讀 Badge | 絕對定位紅點 | `Badge` Widget |
| 二次確認 | Modal 彈窗 | `showDialog` + `AlertDialog` |
| 數據導出 | Blob + URL.createObjectURL | `Share` + 文件寫入 |
