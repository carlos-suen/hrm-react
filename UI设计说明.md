# 🎨 HRM Dashboard UI 設計說明文檔

> 本文檔使用 ASCII Art 繪製各頁面的線框圖，並附帶精確的 Tailwind 類名和顏色規範。
> 所有設計均需同時適配亮色/暗色模式。

## 一、設計系統基礎 (Design Tokens)

### 1.2 間距系統

| Token | 值 | Tailwind | 用途 |
|---|---|---|---|
| xs | 4px | `1` / `p-1` | 圖標與文字間距 |
| sm | 8px | `2` / `p-2` | 緊湊內邊距 |
| md | 16px | `4` / `p-4` | 標準內邊距 |
| lg | 24px | `6` / `p-6` | 卡片內邊距 |
| xl | 32px | `8` / `p-8` | 區塊間距 |
| 2xl | 48px | `12` / `p-12` | 大區塊間距 |

### 1.3 圓角系統

| Token | 值 | Tailwind | 用途 |
|---|---|---|---|
| sm | 4px | `rounded` | Badge、小標籤 |
| md | 8px | `rounded-lg` | 按鈕、輸入框 |
| lg | 12px | `rounded-xl` | 卡片、彈窗 |
| xl | 16px | `rounded-2xl` | 大面板 |
| full | 50% | `rounded-full` | 頭像、圓形按鈕 |

### 1.4 陰影系統

| Token | Tailwind | 暗色模式 | 用途 |
|---|---|---|---|
| sm | `shadow-sm` | `dark:shadow-none` | 卡片 |
| md | `shadow-md` | `dark:shadow-none` | 彈窗 |
| lg | `shadow-lg` | `dark:shadow-none` | 下拉菜單 |

```
  │   ↕↕↕   │   updateLeave    │   ↕↕↕   │
  │          │   Status(id,     │          │
  │          │   'Approved')    │          │
  └──────────┘                  └──────────┘

  拖拽視覺反饋：
  - 拖起時：卡片半透明 + 陰影增大
  - 經過目標列：列背景高亮
  - 釋放後：卡片平滑移動到新列
```
